# Contributing

Thanks for your interest in VV//LIVEWIRE.

This repository holds **release downloads and documentation only**. The app's source code is not public, so pull requests with code can't be accepted.

How you can help:
- **Bugs:** use the in-app **Report a bug** button, or open an issue with the **[VV//LIVEWIRE] Bug** template.
- **Ideas and skin requests:** open an issue with the **[VV//LIVEWIRE] Feature / skin request** template.
- **Docs fixes:** typo or clarity fixes to the README are welcome as issues.

Please don't post personal info, API keys, or chat contents in issues or screenshots.
